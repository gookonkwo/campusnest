# CampusNest Backend

The CampusNest backend is built with Python and FastAPI.

## Run locally

From the `backend` directory:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open these addresses after the server starts:

- API welcome: http://127.0.0.1:8000/
- Health check: http://127.0.0.1:8000/health
- Interactive API documentation: http://127.0.0.1:8000/docs

## Current scope

This is the initial API foundation. Authentication, database integration, accommodation listings, search, and booking requests will be added in later milestones.

## Database setup

The backend uses SQLAlchemy and PostgreSQL. Set the `DATABASE_URL` environment variable before starting the API. For local development, SQLite is used if no URL is supplied.

Example PostgreSQL URL:

```text
postgresql+psycopg://USER:PASSWORD@HOST:5432/DATABASE
```

Do not commit database credentials or place real passwords in source files.

## Database migrations

From the `backend` directory, activate your virtual environment and run:

```bash
alembic upgrade head
```

This creates the database tables defined by the migrations. The first migration creates the `universities` table.

To create a new migration after changing models:

```bash
alembic revision --autogenerate -m "describe the change"
```

Review autogenerated migration files before applying them.
